# Docker Troubleshooting

Things break in Docker all the time. The skill that matters is **diagnosing** quickly, not memorising flags.

In this scenario four things are broken on this machine. For each one you will:

1. Observe the symptom
2. Investigate with the right Docker command
3. Fix it

You will use `docker ps -a`, `docker logs`, `docker inspect`, `docker exec`, `docker network` and `docker build`.

**Prerequisites:** basic Docker knowledge (running containers, images, port mapping).

The environment is being prepared. Wait for the terminal to say **DONE**, then click **START**.
